# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/o11-ai/o11-sdk/security/advisories/new). Never include credentials, customer data or private documents in a public issue.

Use the latest published patch release. OAuth credentials belong in private user-owned local files. Windows additionally uses user-bound DPAPI encryption. macOS/Linux files can be read by processes running as the same user. Never commit credential files. Tracking keys belong on your application server.
