# Contributing

Use Bun 1.4.2 or newer. Run `bun install --frozen-lockfile`, `bun run build`, `bun test` and `bun check-types` before submitting a pull request. Keep changes scoped, preserve authorization checks, and include a regression test when changing behavior.

Do not commit credentials or customer data. See [SECURITY.md](SECURITY.md) for private vulnerability reporting.
